## 📖 About

PlantCare AI is an AI-powered web application that detects plant
diseases from leaf images using a **MobileNetV2** deep learning model
and generates intelligent treatment recommendations with **Google Gemini
AI**. The application is designed for farmers, students, gardeners, and
agriculture enthusiasts to support early disease detection and informed
crop management.

------------------------------------------------------------------------

## ✨ Features

-   🌿 Plant disease detection from leaf images
-   🤖 AI-powered treatment recommendations using Gemini AI
-   📊 Confidence score prediction
-   🛡️ Prevention and disease management tips
-   🌱 Smart farming recommendations
-   ⚡ Fast inference with TensorFlow
-   💻 Responsive Flask web application

## ⚙️ Installation

``` bash
git clone https://github.com/shamith-14/PlantCare-AI.git
cd PlantCare-AI

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

Create a `.env` file:

``` env
GEMINI_API_KEY=YOUR_API_KEY
```

Run:

``` bash
python app.py
```
